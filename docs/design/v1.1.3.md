## 機能要件
- [家系図における養子の書き方](https://kakeizudokoro.com/posts/kakeizu-youshi/) の養子のルールをフォローできる形で実装する
- 特別養子縁組によって子が切り離された後、養父を削除した場合は原状復帰する

### 細則(フェーズ1実装時に決定)
#### 参照した記事のルールと対応
| 記事のルール | 対応 |
| --- | --- |
| 実親子は実線、養親子は破線、配偶者は二重線 | 普通養子の養親子の線を破線にする(実親子・婚姻線は従来どおり) |
| 普通養子は実親・養親の両方と結ぶ | 実親から実線、養親から破線を両方引く |
| 特別養子は養親と実線で結び、実親へは線をつながない(戸籍の表記に合わせる場合) | 戸籍に合わせる書き方を採用。養親と実線で結び、実親とは線を引かない。由来は詳細パネルの「実親」の行で確認できる |
| 婿養子は妻と二重線、妻の親と破線。縁組の無い婿入りは二重線のみ | 夫を妻の親の家族の養子にする操作で表す。縁組しなければ従来どおり二重線のみ |
| 連れ子は縁組して初めて養子(破線) | 子を、継親と実親の家族の養子にする操作で表す。縁組しなければ線は引かない |
| 孫養子は実線と破線の両方 | 祖父母の家族の養子にする操作で表す。世代は実親の子のまま |
| 凡例「破線＝養子」を添える | 破線がある場合に、画面の左上と画像(PNG・PDF)の左下に「破線: 養子(養親子)」を表示する |
| 続柄は戸籍にならい「養子」「養女」 | 詳細パネルの養親の行に「(養子)」「(養女)」、特別養子は「(特別養子)」と添える |
| 出自の注記(実父〇〇の二男) | 両方の親を線で結ぶため注記は描かない。詳細パネルに実親・養親を表示する |

#### データ(GEDCOM)
- 養子縁組は、子の `INDI.FAMC` の `PEDI` で表す(養親の家族の `CHIL` にも子を入れる)
  - 実子: `PEDI` なし(インポートした `PEDI BIRTH` も実子)
  - 普通養子: `2 PEDI ADOPTED`
  - 特別養子: `2 PEDI ADOPTED` + `3 PHRASE 特別養子`(GEDCOM 7.0 に特別養子の区別が無いため、標準の `PHRASE` で補う)
- `PEDI` が `FOSTER`(里子)・`SEALING`・`OTHER` の場合は実子と同じ扱い(記事の対象外のため)
- `ADOP` イベント(縁組日・養親の別)は扱わない(従来どおり `extras` として保持する)

#### 養子縁組の操作
- ノード横のメニューに「養子縁組」を追加する。ダイアログで養親を次から選ぶ
  - 新しい人物を養親として追加: 縁組の種類(普通養子・特別養子。初期値は普通養子)を選び、新しい家族を作る。性別は男女から必須で、性別で養父(HUSB)・養母(WIFE)を決める
  - 「〇〇 の養父/養母を追加」: 養親の枠が空いた縁組の家族がある場合のみ表示。続柄は空いている枠で決まり、性別の初期値はそれに合わせる(変更可)。縁組の種類は家族に従う
  - 「〇〇 の養子にする」: 親が1人以上いて、本人が配偶者・子として属していない既存の家族。人物の入力欄は出さない
- 養親の姓は本人から継承しない(初期値なし)
- 縁組の解除・種類の変更は対象外(縁組の家族の人物を削除するか、GEDCOM を編集して読み込む)

#### 養親の削除(フェーズ2で決定)
- 人物の削除で縁組の家族の親がいなくなった場合(削除した人物が最後の養親だった場合)、その家族への養子縁組を解消し、縁組前の状態に戻す
  - 縁組の家族から子を外し、子の縁組の FAMC を除く。メンバーが0人になった家族は従来どおり削除する
  - 特別養子では線を引かなくなっていた実親と、再び実線でつながる
- 普通養子も同様に解消する(養親のいない縁組は意味を持たないため)
- 養親が1人でも残る場合は縁組を維持する(養父・養母の一方を削除しても、もう一方との縁組は続く)
- 実子は従来どおり、親がいなくなっても家族に残す
- インポートしたデータに元からある親のいない縁組の家族は、無関係な人物の削除では変更しない
- 縁組の解消で家系図が分断される場合は、従来どおり削除できない
- 「親を追加」は実親のみを対象とする。実親の家族(実子としての最初の FAMC)を対象にし、縁組の家族しか無ければ新しい実親の家族を作る(v1.1.2「親の追加」の対象を限定)

#### 描画
- 配置に使う親の家族は、特別養子の家族があればそれ、無ければ実親の家族、それも無ければ普通養子の家族とする。それ以外の普通養子の家族からは、配置済みの子へ線だけを引く
  - 世代も配置に使う親子からたどり、線だけ引く養親子は最後にたどる(子を通じてのみつながる養親は子の1つ上の行に置く)
- 子への線は、子への縦線は子ごとに、親からの縦線・横線(バス)は全員が普通養子の場合に破線とする
- 線を引く担当が決まらなかった家族(配偶者として横に並べた人の、子が全員別の位置にいる家族)も、配置後に線を引く

## 実施記録
### フェーズ1: 養子縁組
#### 実装内容
- `packages/gedcom/src/model/pedigree.ts`(新規): `Pedigree`・`linkPedigree`・`pedigreeOf`(FAMC の PEDI を読む)、`adoptionLink`(縁組の FAMC を作る)、`SPECIAL_ADOPTION_PHRASE`
- `packages/gedcom/src/operations/adopt.ts`(新規): `adoptableFamilies`・`adoptInto`(既存の家族の養子にする)、`vacantAdoptiveFamilies`・`addAdoptiveParent`(養親の追加)、`AdoptionKind`

- `apps/web/src/features/family-tree/layout.ts`: 親子の関係(配置に使う・線だけ引く・線を引かない)の判定、世代・配置・線の対応(「細則 > 描画」)。`LayoutLine.adopted` を追加
- `apps/web/src/features/family-tree/tree-shapes.ts`: 養親子の線を破線にする。`ADOPTION_DASH`・`ADOPTION_LEGEND`・`hasAdoption` を追加
- `apps/web/src/features/family-tree/export/image.ts`: 破線がある場合に凡例の分だけ画像を縦に広げ、左下に描く
- `apps/web/src/features/family-tree/components/`
  - `adoption-form.tsx`(新規): 養子縁組の入力。`add-person-dialog.tsx` に `AddMode` の `adoption` を追加して表示する

  - `tree-legend.tsx`(新規): 画面左上の凡例。`family-tree-view.tsx` で破線がある場合に表示
  - `node-menu.tsx`: 「養子縁組」を追加

- `apps/web/src/features/family-tree/relations.ts`: `parentNamesOf`(家族の親の名前)を追加

#### 設定上の判断
- 特別養子は記事の2つの流儀のうち戸籍に合わせる書き方を選んだ(記事が「養親とは実線で結ぶことが多い」とするため)
- 画像出力の目視確認で、同じ婚姻からブロックをまたいで複数の線を引く場合に、共有した起点がブロックの平行移動で二重に動く不具合を検出し修正した(線ごとに起点を複製)。養子縁組で初めて起こる配置(婿養子の妻の親など)
- 孫養子は、祖父母からの破線が実親への実線と近い位置を通るため、線が込み入って見える(未対処)

### フェーズ2: 養親の削除による縁組の解消
#### 実装内容
- `packages/gedcom/src/operations/remove.ts`: 人物の削除時に、削除した人物だけが親だった家族への養子縁組を解消する(`dissolveAdoptions`)。削除の可否の判定にも同じ結果を使う(「細則 > 養親の削除」)

#### 設定上の判断
- 要件は「特別養子の養父を削除した場合」だが、養母・普通養子にも同じ規則を適用した。原状復帰の条件は「養親が全員いなくなったとき」とした

#### テスト・検証結果
- 単体: `packages/gedcom` 150件、`apps/web` 140件すべて成功
  - `remove.test.ts` に養親の削除の5件(特別養子・普通養子の解消、養親が残る場合の維持、実子の維持、元から親のいない縁組の家族の維持)を追加。`remove.ts` のカバレッジは 100%
- `pnpm lint` / `pnpm typecheck` 成功
- E2E: 40件すべて成功
  - `edit.spec.ts`「新しい人物を特別養子の養親として追加する」に、養親を削除して詳細パネルから養親が消え、GEDCOM 出力に `PEDI` が残らないことの確認を追加
