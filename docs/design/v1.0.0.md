## 機能要件
### データ
- 初期状態として INDI の `@I1@` を起点ノードとしてスタート
  - SUBM と INDI は無関係(SUBM はファイルの提出者情報のみ)
- サンプル .ged を同梱し、初回起動時に読み込む
- .ged ファイルのインポートが可能
- 編集中のデータは localStorage に保存し、リロード後も復元する

### レンダリング
- 日本式の家系図表記
  - 婚姻関係は二重線
  - 兄弟姉妹は横に並べる
- 選択中のノードを中心に上下2世代を表示
  - ノードをクリックすると、そのノードを中心に再描画する
  - 表示範囲は直系+兄弟+配偶者
    - 祖父母(父方・母方)、父母、中心の兄弟姉妹、中心の配偶者、子とその配偶者、孫
    - 叔父叔母・いとこ・配偶者の親・兄弟の配偶者・孫の配偶者は表示しない(クリックで中心を移して辿る)
    - 親・祖父母は最初の親の家族(FAMC)のみを対象とする
- 夫婦は夫(HUSB)が右・妻(WIFE)が左
- 再婚時は配偶者を本人の横に上下に連ねて表示
  - 本人が HUSB なら配偶者は左側、WIFE なら右側(最初の FAMS での枠で決定)
  - 各婚姻の子はそれぞれの婚姻線から線を引き、子の世代は同じ行に揃える
- 世代ごとに行を揃え、親子は親(夫婦の場合は婚姻線の中点)から子の上端へ直角の線で結ぶ
- 個人ノードは姓名を表示し、性別で枠の色を変える(M・F・その他)。中心ノードは強調表示
  - 姓名が空の場合は「名前未設定」
- 操作: ドラッグで移動、ホイール/ピンチで拡大縮小。中心が変わるとその人物を画面中央に移動

### 個人ノード操作
- 画面上部にヘッダー(アプリ名・インポート・エクスポート)。スマホではメニューに集約
- 初期状態は家系図を全幅表示し、詳細パネル・ノード横メニューは表示しない
- レンダリングされた家系図から個人ノードをクリックすると以下の効果(詳細パネルは×で閉じられる。閉じるとメニューも非表示)
    - 画面右半分にその個人の詳細情報を表示
      - 下部のボタンより編集・閲覧モードをトグル
      - スマホでは画面下部からのシート表示(shadcn/ui Sheet)
    - ノードの右側にメニューを表示
      - 親を追加
        - 父/母を選んで追加(父は SEX M・HUSB、母は SEX F・WIFE)
        - 既にいる側は選べない。父母がすでに揃っている場合は表示しない
        - 親の家族(FAMC)が複数ある場合は最初の家族を対象とする
      - 配偶者を追加
        - 常に新しい家族(FAM)を作成する(既存の子とは紐付かない)
      - 子を追加
        - どの配偶者との子かを選ぶ(配偶者一覧 + 「配偶者なし」)
        - 配偶者が1人以下なら選択なしで自動決定
        - 「配偶者なし」は配偶者枠が空いた既存の家族に追加し、無ければ新しい家族を作成する
- 既存ノードを選択し、個人ノードを追加/編集/削除可能
  - 削除は詳細パネルの編集モード下部の削除ボタンから確認ダイアログを経て実行
  - 削除できない場合はボタンを無効にし、理由を表示
- 操作エラーはトーストで表示
- インポートは確認ダイアログ(現在のデータは破棄される旨)の後に置き換える
  - 片方向リンクの補完による警告はインポート後に一覧表示
  - 読み込みに失敗した場合は現在のデータを維持し、エラーを表示
- データ(INDI)が0件の場合は「最初の人物を追加」ボタンを表示
- 人物の入力項目は姓・名・性別
  - 姓または名のどちらかが必須。性別は任意(未入力は不明 U)
- 新しい家族を作成する際の対象者の枠は、SEX が F なら WIFE、それ以外は HUSB。相手はもう一方の枠
- 新規の xref は `I{n}` / `F{n}`(既存の同形式の最大番号 + 1)
- データが空の場合、最初に追加した人物が `@I1@`(起点ノード)となる

### 削除ルール
- 削除により家系図が分断される(矛盾が発生する)場合は削除を禁止
  - 判定: 同じ FAM のメンバー(HUSB/WIFE/CHIL)同士をつながりとみなし、削除後の連結成分数が削除前より増える場合に禁止
  - インポートデータが元から分断している場合、既存の分断は問わない
- 起点ノードの削除は禁止
- 削除の結果メンバーが0人となった FAM は自動で削除
  - 夫婦の片方のみ・子なしの FAM など、メンバーが1人以上残る場合は削除しない

### エクスポート
- .ged, .pdf, .png の形式でエクスポート可能
- エクスポート対象データ(現在のデータ/フィルタ後データ)は注入とし、エクスポート処理とは疎結合にする
  - v1 時点ではフィルタ機能自体は実装しない(展望参照)
- PDF は canvas の画像を埋め込む方式(jsPDF)
  - 文字選択可能な PDF は任意(できれば対応) → v1 では対応しない(日本語フォントの同梱でバンドル・Workers のサイズが増えるため)
- 細則(フェーズ5実装時に決定)
  - エクスポートはヘッダーのメニューから形式(GEDCOM / 画像 / PDF)を選ぶ。スマホはヘッダーのメニュー内に集約
  - v1 の対象データは常に現在のデータ
  - PNG・PDF の描画範囲は、中心人物から上下2世代の家系図全体(画面のパン・ズームに依存しない)。周囲に余白を付け、画面の2倍の解像度で描く
  - 画像では中心人物を強調しない
  - PDF は A4 1ページ。図が横長なら横向き、それ以外は縦向き。余白 10mm に収まらなければ縮小し(拡大はしない)、ページ中央に配置
  - ファイル名は `kakeizu-YYYYMMDD.{ged,png,pdf}`(ローカル日付)
  - INDI が0件の場合、PNG・PDF は選択不可(.ged は出力可)

## 実装要件
- GEDCOMバージョン7.0.18(開発時点の最新)
- 初期で許可する要素(GEDCOM 7.0 の構造に準拠)
  - HEAD
    - GEDC
      - VERS
    - SUBM(SUBM レコードへのポインタ)
  - SUBM
    - NAME
  - INDI
    - NAME
      - GIVN
      - SURN
    - SEX
    - FAMS
    - FAMC
  - FAM
    - HUSB
    - WIFE
    - CHIL
  - TRLR
- 7.0 では文字コードは UTF-8 固定のため HEAD.CHAR は扱わない
- HEAD.GEDC.VERS が 7.x 以外のファイルはインポート不可
- エクスポート時の VERS は `7.0`

### インポート・エクスポート
- 許可リスト外の要素は内部に保持し、UI では表示・編集しない
  - .ged エクスポート時にそのまま出力する(他ソフト由来のデータを失わない)
- 個人名
  - UI は姓・名の2入力
  - 出力は NAME `名 /姓/` と GIVN・SURN の両方
  - 読込は GIVN/SURN を優先し、無ければ NAME の `/姓/` 表記から分解
- 整合性
  - 存在しない xref への参照、HEAD/TRLR の欠落はインポート失敗
  - 片方向のみのリンク(INDI.FAMS ↔ FAM.HUSB/WIFE、INDI.FAMC ↔ FAM.CHIL)は双方向に補完し、警告を表示
- 起点ノード
  - `@I1@` が存在しない場合はファイル内で最初の INDI を起点とする
  - INDI が0件の場合は空状態から1人目の作成を促す
- 細則(フェーズ1実装時に決定)
  - `@VOID@` ポインタはリンク無しとして扱う
  - INDI の2つ目以降の NAME・SEX は許可外要素と同様に保持する(別名等)
  - FAM の HUSB/WIFE の重複、SEX の値が M/F/X/U 以外はインポート失敗
  - 片方向 FAMS の補完先は SEX が M なら HUSB、F なら WIFE、それ以外は空いている枠(HUSB → WIFE の順)。枠が埋まっていればインポート失敗
  - 許可外要素の参照(ポインタ)は検証しない
  - エクスポート時の並び順は HEAD → SUBM → INDI → FAM → 許可外レコード → TRLR。各レコード内は許可要素 → 許可外要素の順(元ファイルの並び順は保持しない)

### `packages/gedcom` の構成
- `syntax/`: タグの意味に関与しない構文層(行の解析・CONT 結合・`@@` エスケープ・シリアライズ)
- `model/`: 許可要素を型付きモデル(`FamilyTree`)に変換する層。許可外要素は `extras` / `extraRecords` に保持
- カスタム要素の追加時は `model/types.ts` に項目を追加し、`import.ts` / `export.ts` の対応タグを増やす。未対応のうちは `extras` に保持されるため、追加前のデータも失われない
- 描画ライブラリは react-konva
- UI 言語は日本語のみ
- スマホ対応必須

### フェーズ3: 配置計算と描画
