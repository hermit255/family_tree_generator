## 機能要件
- 初期状態としてサブミットIDが1の個人ノードからスタート
- レンダリングされた家系図から個人ノードをクリックすると以下の効果
    - 画面右半分にその個人の詳細情報を表示
      - 下部のボタンより編集・閲覧モードをトグル
    - ノードの右側にメニューを表示
      - 配偶者を追加
      - 子を追加
- 既存ノードを選択個人ノードを追加/編集/削除可能
- .ged,.pdf,pngなどの形式でエクスポート可能
