## 機能要件
### フロントエンドのデプロイ構成を Cloudflare Pages + SSG に変更
- OpenNext(Cloudflare Workers 上での Next.js サーバー実行)をやめ、`next build` の静的エクスポート(`output: "export"`)を Cloudflare Pages で配信する
  - 画面・機能の変更はない(v1 はクライアント完結のため、サーバー機能を使っていない)
- 配信対象は `apps/web/out/`(`wrangler.jsonc` の `pages_build_output_dir`)
- プレビューは `wrangler pages dev`、デプロイは `wrangler pages deploy`(いずれも `next build` 後に実行)
- 今後の実装上の制約
  - Next.js のサーバー機能(Server Actions、リクエスト依存の Route Handlers、`cookies()`/`headers()`、Proxy、rewrites/redirects/headers 設定、ISR、既定 loader の画像最適化)は使わない。`next dev` でもエラーになる
  - 動的ルートを追加する場合は `generateStaticParams` で全パスを列挙する。ビルド時に決まらない ID はクエリパラメータで受け取る
  - 認証・D1 へのアクセスは backend(Hono / Cloudflare Worker)側に置き、フロントからは API として呼び出す(README の機能分担どおり)
- 細則(フェーズ1実装時に決定)
  - Pages のプレビューは既定ポートが 8788 のため、compose の `preview` で `--port 8787` を指定し従来のポートを維持する
  - Pages プロジェクト名は従来の Worker 名と同じ `kakeizu-web`

## 実施記録
### フェーズ1: OpenNext から Cloudflare Pages + SSG への移行
#### 実装内容
- `apps/web/next.config.ts`: `output: "export"` を追加
- `apps/web/wrangler.jsonc`: `main`・`assets`・`compatibility_flags` を削除し、`pages_build_output_dir: "out"` に変更
- `apps/web/package.json`: `preview` を `next build && wrangler pages dev`、`deploy` を `next build && wrangler pages deploy` に変更
- `apps/web/open-next.config.ts`: 削除
- `compose.yaml`: `preview` サービスのコメントを更新し、`--port 8787` を追加
- `apps/web/eslint.config.mjs`: 除外対象から `.open-next/**`・`cloudflare-env.d.ts` を削除
- `.gitignore`: `.open-next/` を削除
- `README.md`: デプロイ構成の frontend を Cloudflare Pages(SSG)に変更

#### 追加パッケージ・設定
- 削除: `@opennextjs/cloudflare` 1.20.13(依存の `@opennextjs/aws` もロックファイルから削除)
- 追加なし(wrangler 4.154.0 をそのまま使用)

#### 設定上の判断
- v1.0.0 で無効化した `cacheComponents` / `partialPrefetching` は引き続き未設定(既定値)のまま。静的エクスポートでも問題なくビルドできた

#### テスト・検証結果
- `pnpm --filter web build` 成功。`apps/web/out/` に `index.html`・`404.html`・`_next/static` が出力された
- 単体: `apps/web` 99件、`packages/gedcom` 125件すべて成功
- `pnpm lint` / `pnpm typecheck` 成功
- Pages プレビュー(`docker compose --profile preview up preview`): `/` が 200(title「家系図」)、JS チャンクが 200、存在しないパスが 404
- E2E: 開発サーバー向け 34件、Pages プレビュー向け(`E2E_BASE_URL=http://preview:8787`)34件、いずれもすべて成功
- 未実施: `wrangler pages deploy` による実デプロイ(Cloudflare アカウントでの Pages プロジェクト作成・認証が必要なため)
